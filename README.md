# 🔄 SyncFile — مزامنة الملفات عن طريق الفلاش

برنامج ويندوز بواجهة عربية لمزامنة مجلدات العمل (وورد، إكسل، باوربوينت، PDF، نصوص…) بين أجهزة **لا تتصل بالإنترنت**، باستخدام فلاش USB فقط.

## ⬇️ التنزيل

### [تنزيل أحدث إصدار SyncFile.exe](https://github.com/adelss12/SyncFile/releases/latest)

> قد يظهر تحذير Windows SmartScreen لأن الملف غير موقّع رقمياً. اضغط **More info** ثم **Run anyway**.

## 🧭 الفكرة

```
جهاز المكتب  ⇄  الفلاش  ⇄  جهاز البيت   (ويعمل مع أي عدد من الأجهزة)
```

- **كل جلسة = مجلد.** تضغط **＋ جلسة جديدة** وتختار مجلداً مثل `D:\العمل`، فيُنشأ مجلد بالاسم نفسه على الفلاش.
- على الجهاز الآخر تظهر الجلسة **جديدة**، فتضغط **ربط بهذا الجهاز** ويُنشأ مجلد «العمل» هناك.
- بعدها: وصّل الفلاش ← **فحص ومعاينة** ← **مزامنة الآن** ← أخرج الفلاش.

## 🛡️ لا ضياع لأي ملف

- **لا يعتمد على ساعة الجهاز.** يقارن بصمة كل ملف (SHA-256) بآخر مزامنة؛ فإذا كانت ساعة أحد الأجهزة خاطئة لا تختلط النسخ، ويُنبّهك البرنامج بفارق التوقيت.
- **التعارض:** إذا عُدّل الملف نفسه في جهازين، تبقى النسختان، وتُسمّى الأخرى بالعربية: `تقرير_تعارض_جهاز-المكتب_2026-10-15_1430.docx`.
- **الحذف ينتقل** للجهاز الآخر، لكن **لا شيء يُحذف نهائياً**: كل ملف محذوف أو مستبدل يُنقل إلى مجلد `.نسخ_احتياطية` داخل المجلد (على الجهاز وعلى الفلاش).
- **التعديل يغلب الحذف:** إذا حُذف ملف في جهاز وعُدّل في الآخر، يُبقى المعدّل.
- **نسخ آمن:** يُكتب كل ملف باسم مؤقت ويُتحقق من بصمته قبل استبدال القديم، فسحب الفلاش فجأة لا يُتلف شيئاً.
- **الملف المفتوح في وورد أو إكسل لا يُستبدل**، ويطلب منك إغلاقه.
- **إذا اختفى المجلد** (قرص غير موصول أو مجلد منقول) تتوقف المزامنة بدل أن تحذف كل شيء من الفلاش.
- **فرامل الحذف الجماعي:** إذا كان أكثر من نصف الملفات سيُحذف، يطلب تأكيداً إضافياً.

## 🌟 مميزات أخرى

- معاينة ملوّنة قبل أي تنفيذ: 🟢 متطابق • 🟡 تحديث أو ملف جديد • 🔴 تعارض أو متوقف • 🟠 حذف.
- شريط تقدم مع السرعة، وتقرير لكل مزامنة بصيغتي **HTML** عربي و**CSV** (يفتح في إكسل).
- يتعرف على الفلاش بهويته لا بحرفه (`E:` أو `F:`)، ويلاحظ توصيله تلقائياً.
- يتجاهل الملفات المؤقتة وملفات النظام (`~$` و `desktop.ini` و `Thumbs.db`).
- يدعم الأسماء العربية والتشكيل والأرقام العربية والمسارات الطويلة.
- تحذير إذا كان الفلاش بنظام **FAT32** (لا يقبل ملفاً أكبر من 4 جيجابايت؛ يُنصح بـ exFAT).

## 🛠️ للمطور

```bash
pip install -r requirements.txt
python main.py                          # الواجهة
python -m unittest discover -s tests -v # اختبارات المحرك (محاكاة جهازين وفلاش)
```

| الملف | الوظيفة |
|---|---|
| `syncfile/engine.py` | محرك المزامنة: المقارنة الثلاثية، التعارض، الحذف، التنفيذ |
| `syncfile/fsutil.py` | البصمة، النسخ الآمن، المسارات الطويلة، الملفات المتجاهلة |
| `syncfile/carrier.py` | الفلاش وهويته وجلساته |
| `syncfile/state.py` | حالة الجهاز: آخر مزامنة (SQLite) والإعدادات |
| `syncfile/report.py` | تقارير HTML و CSV |
| `syncfile/ui_arabic.py` | الواجهة العربية (PySide6) |

يُبنى `SyncFile.exe` تلقائياً على خوادم ويندوز من GitHub بعد نجاح الاختبارات وفتح الواجهة، ويُنشر باسم الإصدار في `syncfile/__init__.py`.
