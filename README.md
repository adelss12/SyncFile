# 🔄 SyncFile — مزامنة المجلدات بدون إنترنت (على طريقة GoodSync)

برنامج ويندوز بواجهة عربية يزامن أي مجلدين: على الجهاز نفسه، أو بين الجهاز والفلاش، أو بين قرصين. يعمل **بدون إنترنت وبدون سحابة**، وفكرته وطريقة عمله مثل GoodSync.

## ⬇️ التنزيل

### [تنزيل أحدث إصدار SyncFile.exe](https://github.com/adelss12/SyncFile/releases/latest)

> قد يظهر تحذير Windows SmartScreen لأن الملف غير موقّع رقمياً. اضغط **More info** ثم **Run anyway**.

## 🧭 طريقة الاستخدام

1. اضغط **＋ مهمة جديدة**، واختر **المصدر** (مثل `D:\العمل`) و**الهدف** (مثل `E:\العمل` على الفلاش). المجلدات الفرعية تدخل كلها.
2. اختر نوع المزامنة:
   - **في الاتجاهين:** يصبح المجلدان متطابقين.
   - **نسخ احتياطي من المصدر إلى الهدف فقط**، أو العكس.
3. اضغط **🔍 تحليل**، فتظهر شجرة بكل ملف واتجاهه:

   | الرمز | المعنى |
   |---|---|
   | ⬅ | نسخ من المصدر إلى الهدف |
   | ➡ | نسخ من الهدف إلى المصدر |
   | ✖ | حذف (يُنقل إلى `.نسخ_احتياطية`) |
   | ⚠ | يحتاج قرارك: تعارض أو توقيت غير متوافق |
   | ⊘ | لن يُنسخ |
   | ⇄ | الاحتفاظ بالنسختين |

4. **الزر الأيمن** على أي ملف أو مجلد يغيّر اتجاهه، أو يلغي نسخه هذه المرة.
5. اضغط **⇄ مزامنة**. إذا وُجدت ملفات تحتاج قرارك تظهر نافذة تعرض النسختين (التاريخ والحجم)، والمقترح محدد مسبقاً.

## 🧠 كيف يعرف الأحدث؟

- **في أول مزامنة:** يعتمد على تاريخ التعديل **ومعه الحجم**.
  - الملف الأحدث تاريخاً والأكبر حجماً يُنسخ تلقائياً.
  - إذا كان الأحدث تاريخاً **أصغر** حجماً، ينبّهك أن «التوقيت غير متوافق»، ويعرض الملفين لتختار.
- **بعد ذلك:** يحفظ البرنامج في كل مجلد مجلداً مخفياً صغيراً اسمه `.syncfile`، فيه بصمة كل ملف عند آخر مزامنة. بهذا يعرف بدقة ما تغيّر في كل طرف، **ولا يعتمد على ساعة الجهاز**.

## 🛡️ لا ضياع لأي ملف

- **التعارض لا يُنسخ** حتى تختار: نسخة المصدر، أو نسخة الهدف، أو الاحتفاظ بالنسختين.
- **الحذف ينتقل** للطرف الآخر، لكن إلى مجلد `.نسخ_احتياطية`. يُنظَّف هذا المجلد تلقائياً بعد 30 يوماً، والمدة قابلة للتغيير، أو يمكن حفظه للأبد.
- **التعديل يغلب الحذف.**
- **نسخ آمن:** يُكتب كل ملف باسم مؤقت ويُتحقق من بصمته قبل الاستبدال، فسحب الفلاش فجأة لا يُتلف شيئاً.
- **الملف المفتوح في وورد أو إكسل لا يُستبدل.**
- **حماية من الأخطاء الكبيرة:**
  - إذا اختفى أحد المجلدين، تتوقف المزامنة.
  - إذا كان أكثر من نصف الملفات سيُحذف، يُطلب تأكيد.
  - يرفض البرنامج مزامنة مجلد داخل الآخر.

## 🌟 مميزات أخرى

- **مزامنة تلقائية عند توصيل الفلاش.** تُفعَّل لكل مهمة، وتتوقف لتسألك إذا كان الأمر يحتاج قرارك.
- **يتعرف على الفلاش إذا تغيّر حرفه** (من `E:` إلى `F:`).
- **استثناءات:** مثل `*.bak; مؤقت; صور قديمة/*`.
- **أثناء المزامنة وبعدها:** شريط تقدم مع السرعة، وتقرير لكل مزامنة بصيغتي **HTML** عربي و**CSV**.
- **يتجاهل الملفات المؤقتة** (`~$` و`desktop.ini` و`Thumbs.db`).
- **يدعم الأسماء العربية** والمسارات الطويلة.
- **ينبّه إلى قيود FAT32** (لا يقبل ملفاً أكبر من 4 جيجابايت).

## 🛠️ للمطور

```bash
pip install -r requirements.txt
python main.py                          # الواجهة
python -m unittest discover -s tests -v # اختبارات المحرك
python main.py --smoke                  # اختبار الواجهة بلا شاشة
```

| الملف | الوظيفة |
|---|---|
| `syncfile/engine.py` | التحليل والمقارنة الثلاثية، أنواع المهام، القرارات، التنفيذ |
| `syncfile/meta.py` | المجلد المخفي `.syncfile`: هوية المجلد وسجل آخر مزامنة |
| `syncfile/fsutil.py` | البصمة، النسخ الآمن، الاستثناءات، تنظيف النسخ الاحتياطية |
| `syncfile/state.py` | المهام المحفوظة على هذا الجهاز |
| `syncfile/report.py` | تقارير HTML و CSV |
| `syncfile/ui_arabic.py` | الواجهة العربية (PySide6) |

يُبنى `SyncFile.exe` تلقائياً على خوادم ويندوز من GitHub، بعد نجاح الاختبارات وفتح الواجهة.
